# Персональное руководство (alexmetasky, ступень 1)

> Этот репо — твоя персональная среда развития. Здесь живёт всё, что нужно для одного шага: день, неделя, история, профиль.

## Структура

- **`daily/YYYY-MM-DD.md`** — руководство на текущий день: одно действие, одна помидорка, один вопрос для рефлексии.
- **`weekly/W{N}.md`** — руководство на неделю: ритм, гипотеза, слоты.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).
- **`profile.md`** — текущий RCS-профиль (ступень, bottleneck, неудовлетворённость).
- **`worldview.md`** — нарративная дуга: где сейчас, куда двигаемся.
- **`methods.md`** — активные методы под текущий bottleneck.

## Цикл работы

**Каждый день** — открыть `daily/2026-05-25.md`, прочитать, закрыть 1 помидорку (25 мин), добавить одну строку рефлексии в `history/2026-05-25-reflection.txt`.

**Каждую неделю** (понедельник) — руководство пересобирается автоматически.

## Рефлексия

Рефлексия — текстовый файл в `history/YYYY-MM-DD-reflection.txt`. Одного абзаца достаточно:
- Что закрыл сегодня — что не закрыл
- Что мешало / что помогало (внешнее или внутреннее)

Портной читает рефлексии при следующем рендере и адаптирует контент.

## Пересборка руководства

Команда `/personal-guide-render` в Claude Code пересобирает все файлы по актуальному RCS-профилю и истории рефлексий.
